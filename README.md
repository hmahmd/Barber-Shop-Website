# Barber Shop Website

A fully responsive, single-page website for a barber shop, built with plain HTML, CSS and JavaScript. Created as part of the Trainlyze Frontend Development internship (Week 1, Project 1).

## Features

- Fixed navbar with logo and menu button
- Hero section with a teal gradient overlay and animated hover buttons
- Slide-in side menu (opens and closes with JavaScript)
- "Why Choose Us" features section with icons
- Services grid with a slide-up hover overlay on each card
- Client testimonials with hover lift effect
- Contact footer with opening hours, contact details and social icons
- Fully responsive layout for mobile, tablet and desktop

## Tech Stack

- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, transitions, media queries)
- JavaScript (DOM manipulation)
- Font Awesome icons
- Google Fonts (Poppins, Kaushan Script)

## Project Structure

```
├── index.html
├── style.css
├── script.js
└── images/
```

## How to Run

1. Download or clone the repository
2. Open `index.html` in any browser

No installation or build tools needed.

## Deployment
